# Channels polish list

This is the first polish pass for the channels app, in priority order.
[`../DESIGN.md`](../DESIGN.md) is the contract each item follows. The `compare/`
images put the live app at `4b5708b` on the left and the target mockup on the
right. `before/` holds the live captures, and `after/` holds the mockup captures.
The live captures come from a testbed with real Claude Code and Codex agents. The
mockup in `mockup/index.html` uses the same messages.

To rebuild the evidence, run `node design/shoot-mockup.mjs design/after`, then
`node design/shoot-live.mjs '<mint-url command>' design/before testbed`, then
`design/compare.sh`. `before/needs-you-unanswered.png` is cropped from the operator's UI-2 review capture, because the testbed run did not reproduce the ND-DELIVERY-003 warning. `node design/contrast.mjs` checks the tokens.

## Status

Phase B implemented every item above. `reports/DESIGN-2.json` in the
orchestration state records the status of each item, the checks, and the perf.
`phase-b/` holds the live captures: four views at 1440 by 900 and 1024 by 700 in
both themes, and `walkthrough.mp4`, 51 seconds. To rebuild them against a kept
testbed, run `node design/shoot-phase-b.mjs '<mint-url command>' design/phase-b
'<live send command>'`, then convert `walkthrough.webm` with
`ffmpeg -i walkthrough.webm -c:v libx264 -crf 28 -pix_fmt yuv420p walkthrough.mp4`.
Playwright's video capture needs its own ffmpeg build. A symlink from
`~/.cache/ms-playwright/ffmpeg-1011/ffmpeg-linux` to the system `ffmpeg` works.

## Data asks for the builders

These items are not design work. They would make items 2 and 5 better, and they
need a Namedrop change.

- Attention cards carry no subject. The banner cannot say which agent an
  unanswered request belongs to, or link to the message. Adding
  `subject_alias` and `message_id` to `AttentionCard` in
  `src/dashboard/snapshot.rs` would fix both.
- The frame already sends `terminal_runs` with `exit_code`, but `wire.ts` drops
  it. Parsing it lets the UI show "Exit 0" without reading the reply text.
- The CSP has no `font-src`, so the app cannot bundle a typeface. DESIGN.md uses
  system fonts for that reason. Adding `font-src 'self'` would allow a bundled
  face later. Nothing in this pass needs it.
